# Divine Reels

Static site for showcasing Bible-inspired short-form reels with donation and subscription modals.

## Development

Open `index.html` in your browser to explore the experience. Styles live in `assets/style.css` and interactions in `assets/script.js`.

## Publishing to GitHub Pages

1. Commit the latest changes and push them to the `main` branch of your fork.
2. In GitHub, go to **Settings → Pages** and choose `Deploy from a branch` with the `main` branch and `/ (root)` folder.
3. Save. GitHub Pages will build the site and serve it at `https://<your-username>.github.io/Divine-Reels/` once the deployment completes.

All asset URLs are relative (e.g. `./assets/style.css`), so they will resolve correctly whether you open the site locally or from the GitHub Pages domain.
